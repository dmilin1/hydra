# Chat

Reddit Chat lets you have direct conversations with other Reddit users. Reddit has replaced private messages with chat, and chat isn't available through Reddit's API, so Hydra opens Reddit's own chat interface inside the app. You need to be logged in to use chat.

## Opening Chat

Tap the **chat bubble icon** in the top-right corner of the [Inbox](hydra://settings/guide/?doc=inbox) tab. Your conversations open right inside Hydra, signed in with your current account. From there you can read and reply to existing conversations or start new ones, just like on Reddit.

## Starting a Chat with a User

To start a chat with another user:

1. Open the user's **profile page**
2. Tap the **three-dot menu** in the top-right corner
3. Select **"Message"**

This opens a chat with that user.

## Links in Chat

Tapping a link to a Reddit post, comment, subreddit, or user inside a chat opens it directly in Hydra. Links to other websites open according to your [External Links](hydra://settings/guide/?doc=external_links) settings.

## Things to Know

- Chat runs on Reddit's web interface, so Hydra's themes and swipe actions don't apply inside it.
- Chat is separate from your Inbox. The Inbox shows replies to your comments and posts, and its unread badge doesn't include chat messages.
